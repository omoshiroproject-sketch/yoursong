## 静的か、サーバーが要るか

**ほぼ純粋な静的サイト。** フォーム送信・API 呼び出し・決済処理はページ内に無い。申し込み導線はすべて LINE（`https://lin.ee/QiPtkmg`）へのリンク。

JS が行う通信は次だけで、いずれも同一ホストの静的ファイル:
- 試聴: `fetch('/audio/<曲名>.mp3')`（`assets/SongSamples-*.js`、11曲）
- ページ間移動（vinext / React Server Components）: リンククリック時に `<パス>.rsc` を取得（例 `/legal/privacy.rsc`、トップは `/.rsc`）。これらも保存済み。
  - 静的サーバーでは `.rsc` を `Content-Type: text/x-component` で返す設定が要る可能性あり。失敗しても通常のページ遷移に切り替わるのが一般的だが、移設後に要確認。
  - クエリ（`?_rsc=...`）が付くことがあるが、静的サーバーは通常クエリを無視するので問題ない見込み。
- フレームワーク内に Server Action 用コードはあるが、このサイトでは使われていない（`<form>` なし）。

下層ページは `legal/<名前>/index.html` に保存した。`/legal/privacy`（末尾スラッシュなし）でも開けるよう、サーバー側で `/legal/privacy` → `/legal/privacy/index.html`（または `/legal/privacy/` へリダイレクト）になる設定が要る。Apache / nginx / Netlify 等は既定でほぼ対応。
